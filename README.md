# Trato

Trato ayuda a negocios de servicios a tener a la vista el dinero de sus cotizaciones abiertas y retomar la conversación por WhatsApp con un mensaje listo.

## Demo

Aplicación estática, sin dependencias ni build step. Abre `index.html` o publica el directorio raíz en Vercel.

## Funciones

- Tablero de cotizaciones pendientes, valor abierto, seguimientos y cierres.
- Registro de cotizaciones, búsqueda, filtros y cambios de estado.
- Acceso a WhatsApp con seguimiento personalizado para el cliente.
- Vista de clientes y configuración del perfil.
- Almacenamiento local en el navegador para esta demo.

## Alcance actual

Esta versión es una demo funcional para validar interés comercial. Los datos viven en el navegador actual; todavía no incluye cuentas, sincronización entre dispositivos, pagos ni envío automático de WhatsApp.
